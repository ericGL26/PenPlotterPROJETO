

Objetivo do programa: Eu tô construindo um Pen plotter que vai escrever numa folha de papel da mesma forma que um humano escreveria.
Não quero fazer nada relacionado a hardware ainda. 
O objetivo é criar um programa que vai Ter um banco de dados de caligrafias que eu gostaria de replicar 
E que também terá a funcionalidade de Pegar qualquer texto e mandar para esse hardware o comando de imprimi-lo na caligrafia que eu selecionar. 

Quero dividir esse programa em duas partes. 

1 - construir um banco de dados de caligrafias a partir de uma fotografia de uma folha escrita à mão.
Então aqui eu quero fazer o upload de uma imagem Dar um nome pra essa caligrafia E que todo o padrão de letras fique salvo para posteriormente utilizar 

2 -  Programa python que o usuário inpute um texto e transcreva esse mesmo texto para fotografia usando os caracteres escritos a mão de uma das caligrafias que estiverem salvas no banco de dados.


Obs: eu já tenho o programa que vai pegar a foto e gerar o gcode para mandar ao hardware, então essa parte não precisa ser especificada será acoplado posteriormente ao projeto.
